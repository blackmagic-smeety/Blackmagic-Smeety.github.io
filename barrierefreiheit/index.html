Barrierefreiheit der Blackmagic Smeety Website

Die offizielle Website von Blackmagic Smeety unterstützt Tastaturbedienung, sichtbare Fokusmarkierungen, semantische Beschriftungen für Screenreader, Alternativtexte für inhaltlich relevante Bilder, eine Direkt-zum-Hauptinhalt-Funktion und die Systemeinstellung zur Reduzierung von Bewegungen. Barrierefreiheit wird fortlaufend weiterentwickelt. Eine vollständige formale Konformität mit einem bestimmten Barrierefreiheitsstandard wird nicht behauptet. Hinweise zu Barrieren können an blackmagic.smeety@gmail.com gesendet werden.

Accessibility of the Blackmagic Smeety website

The official Blackmagic Smeety website supports keyboard navigation, visible focus indicators, semantic labels for screen readers, alternative text for meaningful images, a skip-to-main-content function and the system preference to reduce motion. Accessibility is continuously improved. Full formal conformance with a specific accessibility standard is not claimed. Accessibility barriers can be reported to blackmagic.smeety@gmail.com.
